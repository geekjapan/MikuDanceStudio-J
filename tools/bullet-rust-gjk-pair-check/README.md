# Outer GJK and mixed convex manifolds

`core/gjk_pair.rs` translates the vendored MMD `btGjkPairDetector` query over the already translated nonvirtual support, external Voronoi simplex and internal GJK/EPA adapter. `PairManifold` routes sphere-box, sphere-capsule and box-capsule in both orders through this detector. Dedicated sphere-sphere, box-box, capsule-capsule and convex-plane routes remain selected first. Plane-plane remains unsupported. The process API requires the caller's shared mutable simplex. The future World dispatcher must own that configuration-level solver.

```sh
python3 tools/bullet-rust-gjk-pair-check/check.py --out-dir /tmp/mds-gjk-pair
```

Sphere-capsule fallback is reachable with finite positive dimensions. The directed sphere-capsule and capsule-sphere cases use tiny radii and rotated capsules. In `btConvexShape::localGetSupportVertexWithoutMarginNonVirtual`, sphere support is zero. Ideal capsule support is a segment endpoint because radius equals margin at identity scaling. Native capsule support nevertheless evaluates `(pos + vec * radius) - vec * margin` in float. This expression can round differently from `pos`, and the outer simplex and internal GJK use different reductions and operation associations. Segment geometry in real arithmetic therefore does not prove floating-point branch unreachability.

The actual native route is `btGjkPairDetector::getClosestPoints` calling `calcPenDepth`, whose `Penetration` call fails and whose `Distance` call supplies defined witnesses and a nonzero axis.
