# 移植与验证状态

更新：2026-10-24。行为基准是 MikuMikuDanceE v9.32 x64；二进制身份与验证规则见 [x64 重建基准](X64_RECONSTRUCTION.md)。项目没有全库严格等价证明，也不声称取得原作者源码。

## 当前实现

- MME 作为静态库并入宿主，设备、场景和绘制边界由宿主桥接；相关模块见 [架构](ARCHITECTURE.md)。
- 应用与本地 Bullet 源码中的手写汇编和裸函数已替换或移除。x86 数值兼容仍依赖特定浮点表达式和编译选项；SSE intrinsic 不属于手写汇编。
- 帧定位已按显示、表情和骨骼轨道拆分，修复了跨数组成员写入。帧复制粘贴、全局轨道注册分别维护，PMM v2 配置恢复按阶段组织，保留原调用顺序。
- 原版 x64 复核后，修正了全局轨道第 0 帧覆盖、PMM v2 相机参照模式恢复、x64 骨骼位置插值的单精度舍入。
- 运行时类型恢复尚未完成，仍有字节偏移、外置状态和未恢复区域。固定格式长度、资源 ID、原版字符串、数学常量和求值顺序须按其用途保留。

上述重构的基线、数值约束与测试范围集中在 [源码重构与数值兼容](reconstruction/source_refactoring.md)。历史修复依据见 [对齐归档](archive/alignment_worklog_2026-09_10.md)。

## 最近验证

2026-10-24 的本地 Release 构建与完整 CTest：

| 架构 | 结果 | 覆盖说明 |
|---|---|---|
| x64 | 48/48 通过 | 包含全局注册、PMM 播放选项、D3DX 运行时和 GPU 测试 |
| x86 | 47/47 通过 | 包含上述回归及 x86 数学回归 |

帧定位每架构覆盖 880 个场景的姿态位模式、返回值和物理通知顺序。x86 基线保持不变，x64 基线按原版位置插值舍入修正，来源见重构记录。新增注册和 PMM 用例能在修复前实现上复现失败。曲线求值和物理通知使用测试替身，不能由此推断真实 Bullet、完整 GUI 或原程序图像全面一致。

测试数量与环境可能随版本变化。复现构建和测试使用 [发布说明](RELEASES.md#reproduce-the-release-build)；D3D9 曾在部分会话状态下不可用，调查见 [运行时记录](reconstruction/d3dx_runtime_failure.md)。
