# 视线、半角向量、点积与幂函数的分段对照

承接 [高光顶点与插值分离](RHI_SPECULAR_VERTEX_ORIGIN.md)。本次找到了能解释当前保存三角形高光强度的两项运算候选：局部视线参与半角向量求和时使用融合乘加；相机坐标先组合 world×view，再对对象坐标求值。它们只存在于诊断代码，尚未接入生产后端，也未完成完整场景图像验收。

## 输入和观测范围

`tests/model_specular_stages_fixture.hpp` 增加 `--model-specular-stages`。从 x86 第 5 帧、第 23 次绘制归档选取三角形 1362，通过原有共享 measured VS 的 stream output 取得相机坐标、有效法线、未经归一化的相机空间灯光、视线、半角向量和点积。DX9 原生高光参考继续使用循环首顶点的平面着色控制。

独立几何使用程序生成的三角形，世界／视图矩阵为单位矩阵；将 Z 增加 4，使局部视线和法线形成正点积，投影固定到可见深度。这样各段 `log2` 有有限输入，能够验证未被零值钳制隐藏的高光运算。留出几何再改变法线和原材质指数。相机坐标、法线、灯光、固定视线、固定半角向量与点积／指数以相同 float32 字节送入两个显式顶点着色器。

DX9 显式 VS3 通过恒定 `TEXCOORD0` 和 float32 目标观测，检查全部覆盖像素恒定；DX11 VS5 通过 SO 读取三个顶点，要求三者相同。恒定值回传控制逐位等于输入，且显式计算的高光强度重现原 DX11 输出，防止观测路径自己引入舍入。

23 个显式阶段包括：

- 相机向量的长度平方、倒平方根和归一化视线。
- 灯光的长度平方、倒平方根和归一化方向。
- 灯光加固定视线、和向量长度平方、倒平方根及半角向量。
- 固定法线与半角向量的点积。
- 固定点积的 `log2`、乘指数、`exp2` 和 `pow`。
- 完整强度、固定视线后的强度、固定半角向量后的强度。
- 恒定值回传门禁，以及融合求和、融合半角向量、对应点积和强度。

固定功能内部寄存器没有被直接捕获。下面的轴响应和有限扫描均明确标为间接观测。

## 原生归一化与幂函数控制

对相同的 `-camera` 和 `towardLight+viewer`，分别作为待归一化法线，使用正负轴向灯光读取各分量。27 个带重复的输入中，归一化法线的轴响应全部与显式结果一致；相同原始灯光方向的轴响应也一致。这验证了所测归一化操作，不能将其直接当作隐藏的局部视线寄存器。

为隔离幂函数，固定世界／视图为单位矩阵，局部视线关闭，灯光和视线均为 `(0,0,-1)`，半角向量因而沿负 Z。关闭法线归一化，输入法线 `(0,0,-d)`，材质与灯光高光颜色全 1，得到原生 `pow(d,power)` 的可观测输出。

围绕九个捕获点积各扫描 ±4 ULP，对指数 1、2、5 取值：243 组独立输入，每组三次。原生固定功能、DX9 显式 VS3、DX11 VS5 的输出全部一致。因此当前差异不需要用另一个幂函数或最终颜色舍入去抵消。

同时要求一个扫描点积在三个指数上都匹配原生原批次：保存三角形的三个顶点分别唯一匹配偏移 `-1,0,+1 ULP`；独立及留出几何均匹配 `0 ULP`。这些是当前扫描范围内的有效输入约束，不是隐藏点积寄存器的直接读回。

## 半角向量的因果约束

将相机位置、有效法线和原始相机空间灯光直接放入单位变换的小三角形，单独检验这条固定功能高光表达式。只改变投影将三角形放到屏幕，投影不参与视线计算。

单位变换重建在保存顶点 0、1 上重现原批次的指数 1、2、5 输出；顶点 2 未通过这项门禁。后者的重建结果不能冒充原批次参考。

对重建表达式，再以三个带符号的轴向法线观测高光，并用独立的原生 `pow` 扫描校准分量。每个分量都同时匹配指数 1、2、5，避免把 `pow(x,1)` 当作原始点积。27 个分量中 25 个得到唯一候选；另两个分量存在相邻两值的歧义，保留为不确定观测。

保存三角形的重建表达式中：

| 顶点 | 半角向量 X 的量值偏移 | Y 偏移 | Z 的量值偏移 |
|---|---:|---:|---:|
| 0 | -1 ULP | 0 | 0 |
| 1 | 0 | 0 | 0 |
| 2 | -1 ULP | 0 | 0 |

将唯一推断的半角向量送入显式点积，再送入校准过的原生／显式幂函数，7 个可完整推断的顶点都精确重现重建表达式的高光强度。偏差因此可以追到半角向量求和之前的舍入，而非依赖后续颜色误差抵消。

## 两项受控运算候选

第一项候选保留相同长度平方、`rsqrt`、半角归一化、点积和幂函数，只改变视线乘法与灯光相加的舍入边界：

```text
inverse = rsqrt(dot(camera, camera))

基线：viewer = float32(-camera * inverse)
      halfSum = float32(towardLight + viewer)

候选：halfSum[c] = float32(double(-camera[c]) * double(inverse)
                          + double(towardLight[c]))
```

DX9 显式控制使用 `mad`，DX11 诊断使用已有 `Dx9FusedStep`，逐项比较实际 GPU 输出。候选的半角向量逐位匹配全部 25 个唯一分量约束；在可完整推断的七个顶点上，点积和强度均通过因果重现门禁。

对保存顶点 0，相加前的 X 值从基线 `0.5325796604156494` 变成候选 `0.5325796008110046`；归一化后的 X 也减少 1 ULP。普通归一化轴控制相同，而融合求和能解释变化，定位范围比直接替换 `normalize` 更具体。

第二项候选处理原批次与单位变换重建仍不同的相机求值。先按 K=0..3 的顺序组合 world×view：每个乘积及每次相加分别舍入到 float32；再使用已有 fused 四项点积计算相机坐标。诊断只改变高光使用的相机计算，位置仍走既有 measured 裁剪路径。

诊断暂在 shader 中显式展开组合，用于约束运算顺序。若后续验收通过，正式实现应在共用常量准备层计算一次 world×view，由 DX11/DX12 共用；不应把这段矩阵组合重复放进每个顶点，也不应让 CPU 场景层携带驱动舍入规则。

| 相机求值与高光求和 | 保存几何 9 个顶点／指数输入的失败数 | 独立几何失败数 | 留出几何失败数 |
|---|---:|---:|---:|
| 基线相机 + 融合高光求和 | 3 | 0 | 0 |
| world、view 分别 fused 求值 + 融合高光求和 | 3 | 0 | 0 |
| 先组合 world×view、再 fused 求值 + 融合高光求和 | 0 | 0 | 0 |

两个候选组合后，三个几何各三顶点、三个指数，27 个强度输入均精确匹配原生参考，各重复三次。指数扫描和候选原生参考均明确使用 1、2、5；留出几何原材质的 7.3 还用于显式分段观测，不宣称已完成其原生候选验收。
