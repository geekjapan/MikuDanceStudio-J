# vkd3d-shader source

The vkd3d-shader library in this package (libvkd3d-shader.1.dylib, libvkd3d-shader.so.1, or libvkd3d-shader-1.dll) is built by `tools/vkd3d/build.sh` of MikuDanceStudio-J from the vkd3d 2.1 release with the patches in `patches/` applied:

- source: https://dl.winehq.org/vkd3d/source/vkd3d-2.1.tar.xz
- sha256: 7510146aff2adfb4ae07ab890701a607e5ff7c66e57100cfc9f630ec92eeda6a
- patch: `patches/0001-vpos-vface-io.patch`

The build script and the patches are also in the MikuDanceStudio-J repository, <https://github.com/geekjapan/MikuDanceStudio-J>, under `tools/vkd3d/`.
